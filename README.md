# Entropy Lite

Institutional-grade market intelligence system. Structural analysis, liquidity flow detection, and predictive decision modeling for serious investors.

## Tech Stack

- **Frontend:** React, TypeScript, Vite, Tailwind CSS, shadcn/ui
- **Backend / Database:** Supabase

## Getting Started

### Prerequisites

Ensure Node.js or Bun is installed.

### Installation

```bash
npm install
```

### Development Server

```bash
npm run dev
```
